# 随机选择器 PWA

在线地址：https://chloeh88.github.io/Random-Number-Generator/

网页提供两个互相独立的模式：

- “随机整数”从指定的闭区间中生成整数。
- “随机选项”从最多 100 个自定义选项中抽取结果。

所有随机计算均在设备本地完成，输入与结果不会上传或保存。首次成功打开后，可从 iPhone Safari 添加到主屏幕并离线使用。

Motivation: 选择困难症每天纠结去哪吃饭，遂给附近街区编了号，这两周每天用google搜出来的random number generator决定去哪吃饭，但是总抽出某几个数字，感觉不够随机，自己做一个叭
